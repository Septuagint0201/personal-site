I'm glad you stopped by. I hope you find something interesting here that brings a smile to your face!

## Glass Lab

主页 `index.html` 已应用用户确认的 Liquid Glass 材质。独立测试页为 `glass-lab.html`；测试页调整不会自动覆盖主页。

在项目目录启动静态服务器，再访问 `http://127.0.0.1:8765/glass-lab.html`：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

- 四种预设：清透水晶、柔雾丝绒、厚液态、光谱棱镜。
- 同场比较流光、原站插画、折射网格，支持明暗场景与主预览折射开关。
- 调整折射率、厚度、雾度、色散、染色；拖动卡片顶部或用方向键移动，Home 键居中。
- 「选择这组预设」将当前参数保存至该浏览器、该来源的 `localStorage`，刷新可恢复。「导出参数」下载带版本号的 JSON。

当前自定义基线来自用户最终确认的 `septuagint-glass-liquid (1).json`：折射率 1.70、厚度 60px、雾度 1.5px、色散 0.12、遮罩 15%，反转遮罩（深色场景用白色、浅色场景用深色）。可切换原版配色，点击「试用 20%」观察差异，或「恢复我的参数」回到这组基线。0% 时两种配色视觉相同。

「边缘厚度曲线」可对照原版倒角、圆弧和默认的双曲缓入。双曲缓入用有理双曲映射 `q(t) = (1+b)t / (t+b)`，厚度轮廓为 `h(t) = 1 - (1-q)³`。在接入平面的 `t=1` 处，一、二阶导数均为零（C2 连续）。当前过渡范围由倒角宽度的 1.75 倍增加至 2.4 倍（约再加宽 37%），短控件的上限从短边半长的 92% 增至 97%。根据实际加宽比例 `r`，使用 `b = 1 / (1.1r(1+1/0.85)-1)` 保持外缘斜率仅比上一版提高 10%，使卡片和短按钮都不过度变陡。法线来自高度的解析导数，局部厚度与边缘阴影共用这条曲线，平面内部去掉额外的鼓包法线。圆弧版仍使用 `sqrt(1 - edge²)`，供同参数对照。卡片和内部按钮共用选择的截面，平面圆角半径不变。

导出格式 v4 包含 `tintMode`、`edgeProfile` 和 `baselineRevision`。首次采用这份明确指定的 JSON 时，以文件参数和新曲线初始化，避免旧浏览器保存覆盖它；旧保存不会被自动删除或改写。用户再次点击选择后，后续刷新恢复当前基线下的新保存。

渲染使用无依赖 WebGL 1：圆角曲面法线 + GLSL `refract` 计算采样偏移，RGB 折射率差异模拟色散，多点采样模拟雾度。两张 framebuffer 交替合成，内部按钮能够折射父卡片已经渲染的背景。文字与链接保留为可访问的 DOM。

这是场景纹理的屏幕空间折射，不是完整三维光线追踪，也不会捕获任意 DOM 作为背景。无 WebGL 或上下文丢失时显示明确的磨砂降级提示。采用按需渲染，空闲时没有持续动画循环；尊重减少动态效果设置，主预览像素比上限 1.5，对比样本上限 1.25。

## Homepage

`site.js` 固定使用最终确认的参数，`site.css` 负责主页布局，`liquid-glass.js` 提供主页与测试页共用的渲染器。主卡片、六个链接、主题按钮均参与折射；嵌套按钮沿用测试页的厚度、雾度与染色缩放。原插画、头像、社交链接、打字效果、粒子与深色/浅色/系统主题切换保留。指针控制表面光照，玻璃外形保持与背景采样位置对齐。

主页粒子和 3D 背景绘入被折射的场景纹理，最多每秒更新 30 次。3D 背景在视角静止时缓存，只在视角、主题、图片或尺寸变化时重建；背景缓冲上限为 120 万像素，前景合成缓冲上限为 180 万像素。页面不可见、用户减少动态效果或 WebGL 降级时停止粒子动画。缺少 WebGL 时保留可操作的 CSS 玻璃界面，JavaScript 不可用时也能读取内容及使用所有链接。

首页装饰围绕个人宇宙主题：页眉字标、星点、椭圆轨道、两侧留白文字与页脚。星点和轨道由背景渲染器绘制，同样参与玻璃折射；1000px 及以下隐藏两侧文字。链接增加分区标识与方向箭头，箭头仅在悬停或键盘聚焦时轻微移动，并遵循减少动态效果设置。

按钮悬停放大至 1.025 倍，按下缩小至 0.97 倍；过渡期间逐帧同步玻璃边界和圆角。主题按钮使用较弱的反射与边框，按钮高光随光标位置变化。首页独立启用半径 170px 的柔和光标透镜（已确认采用强度 -0.13 的反向压缩效果），在玻璃合成前对背景、轨道与粒子统一折射；DOM 文字和点击区域保持稳定。粒子沿缓慢变化的二维流场持续漂移，基础速度约 15–50px/s；10 个采样点形成轻微渐隐尾迹。光标在 240px 范围内平滑向外排斥粒子，越靠近中心推力越强，仅保留轻微切向漂移；流场弯曲与转向响应减弱，低阻尼使离开后保留约两秒量级的惯性。粒子从屏幕外循环进入，避免碰边反弹；跨边时清空尾迹。减少动态效果时停用透镜、粒子动画和按钮缩放。

背景采用用户确认的 `septuagint-depth-strata.json`：错层叠影（strata），透视幅度 15°、玻璃厚度 31、反光 48%。三层玻璃随光标平滑转动，离开窗口后回正；触屏不触发跟随。主页与实验页共用 `depth-background.js`，保留同一套折射与反光计算。导出文件的浅色主题用于方案预览，主页继续尊重已有的深色/浅色/系统选择。原有前景材质、按钮交互和光标透镜保持不变。

## Depth Lab

背景实验页：`http://127.0.0.1:8765/depth-lab.html`。`depth-lab.html`、`depth-lab.css`、`depth-lab.js` 提供独立的预设比较界面，与主页共用背景渲染器，包含悬浮晶板、错层叠影、弧光透镜、折光屏风四种预设。移动光标调整相机角度，也可聚焦预览后使用方向键调整、Home 回正；支持冻结视角、明暗切换、隐藏前景卡片，以及透视幅度、玻璃厚度和反光强度调节。

背景使用 WebGL 相机射线与倾斜平面求交，通过曲面法线、Snell 折射采样、Fresnel 和环境反光近似玻璃。弧面采用法线近似，叠片为按深度合成，不是完整三维路径追踪。背景结果作为场景纹理交给现有前景玻璃渲染器，因此前景能折射动态背景，字体保持平直。两个缓冲分别限制在 120 万像素，运动上限 30fps；静止、冻结、页面不可见时停止动画，减少动态效果时禁用光标跟随并保留键盘手动调节。

「选择这组背景」仅保存到独立的 `septuagint-depth-choice` 本地存储项；「导出参数」生成 `septuagint-depth-<preset>.json`（v1），包含预设、透视幅度、厚度、反光和主题。两者都不会自动修改或部署主页。

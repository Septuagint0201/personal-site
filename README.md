当前自定义基线来自用户最终确认的 `septuagint-glass-liquid (1).json`：折射率 1.70、厚度 60px、雾度 1.5px、色散 0.12、遮罩 15%，反转遮罩（深色场景用白色、浅色场景用深色）。可切换原版配色，点击「试用 20%」观察差异，或「恢复我的参数」回到这组基线。0% 时两种配色视觉相同。

「边缘厚度曲线」可对照原版倒角、圆弧和默认的双曲缓入。双曲缓入用有理双曲映射 `q(t) = (1+b)t / (t+b)`，厚度轮廓为 `h(t) = 1 - (1-q)³`。在接入平面的 `t=1` 处，一、二阶导数均为零（C2 连续）。当前过渡范围由倒角宽度的 1.75 倍增加至 2.4 倍（约再加宽 37%），短控件的上限从短边半长的 92% 增至 97%。根据实际加宽比例 `r`，使用 `b = 1 / (1.1r(1+1/0.85)-1)` 保持外缘斜率仅比上一版提高 10%，使卡片和短按钮都不过度变陡。法线来自高度的解析导数，局部厚度与边缘阴影共用这条曲线，平面内部去掉额外的鼓包法线。圆弧版仍使用 `sqrt(1 - edge²)`，供同参数对照。卡片和内部按钮共用选择的截面，平面圆角半径不变。

导出格式 v4 包含 `tintMode`、`edgeProfile` 和 `baselineRevision`。首次采用这份明确指定的 JSON 时，以文件参数和新曲线初始化，避免旧浏览器保存覆盖它；旧保存不会被自动删除或改写。用户再次点击选择后，后续刷新恢复当前基线下的新保存。

渲染使用无依赖 WebGL 1：圆角曲面法线 + GLSL `refract` 计算采样偏移，RGB 折射率差异模拟色散，多点采样模拟雾度。两张 framebuffer 交替合成，内部按钮能够折射父卡片已经渲染的背景。文字与链接保留为可访问的 DOM。

这是场景纹理的屏幕空间折射，不是完整三维光线追踪，也不会捕获任意 DOM 作为背景。无 WebGL 或上下文丢失时显示明确的磨砂降级提示。采用按需渲染，空闲时没有持续动画循环；尊重减少动态效果设置，主预览像素比上限 1.5，对比样本上限 1.25。

## Depth Lab

背景实验页：`http://127.0.0.1:8765/depth-lab.html`。`depth-lab.html`、`depth-lab.css`、`depth-lab.js` 提供独立的预设比较界面，与主页共用背景渲染器，包含悬浮晶板、错层叠影、弧光透镜、折光屏风四种预设。移动光标调整相机角度，也可聚焦预览后使用方向键调整、Home 回正；支持冻结视角、明暗切换、隐藏前景卡片，以及透视幅度、玻璃厚度和反光强度调节。

背景使用 WebGL 相机射线与倾斜平面求交，通过曲面法线、Snell 折射采样、Fresnel 和环境反光近似玻璃。弧面采用法线近似，叠片为按深度合成，不是完整三维路径追踪。背景结果作为场景纹理交给现有前景玻璃渲染器，因此前景能折射动态背景，字体保持平直。两个缓冲分别限制在 120 万像素，运动上限 30fps；静止、冻结、页面不可见时停止动画，减少动态效果时禁用光标跟随并保留键盘手动调节。

「选择这组背景」仅保存到独立的 `septuagint-depth-choice` 本地存储项；「导出参数」生成 `septuagint-depth-<preset>.json`（v1），包含预设、透视幅度、厚度、反光和主题。两者都不会自动修改或部署主页。

## Unified UI release

`ui-glass-preset.js` 是两个站点的正式 UI 材质来源；章节场景中的玻璃雕塑、液滴和沙漠晶体不使用该 UI 预设。YARD 的面板、按钮、质量菜单、摇杆和对话框复用主页闭合截面渲染器；目录卡片和三角箭头通过 `yard/src/ui-glass-optics.js` 读取同样的参数与最多三次界面退出。小尺寸圆角和肩宽根据形状内切半径缩短，三角箭头保留三角外形。

YARD UI 在场景最终绘制后保留帧快照，最多 30Hz 更新材质，暂停后的末帧和弹层仍可刷新。两张合成缓冲先初始化一次，后续只同步上一控件覆盖的矩形，避免每个按钮都复制整个屏幕；嵌套折射顺序保持不变。局部与完整合成已在浏览器中对照读回 5,760,000 字节，差异为零。菜单卡片改用本帧背景纹理，避免为每个折射/雾度样本重复求解整套程序背景。

发布 Candy 时只打包入口、生产脚本、样式、两张图片和图标许可；对脚本/样式生成内容哈希文件名，再最后替换入口 HTML。YARD 先上传带哈希的资源，再替换章节与目录 HTML，保留旧哈希资源。Lab、开发工具和源码归档不进入新发布包。

## Transfer maintenance — 2026-10-20

迁移后的站点继续使用配置好的 `septuagint-vm1` SSH 别名，不固定服务器 IP。发布流程现在可重复执行：先运行 `npm run build --prefix yard`，再运行 `node tools/build-release.mjs <新的输出目录>`。输出包含 Candy 和 YARD、SHA-256 清单及 Brotli 11 / gzip 9 预压缩副本。原始文件与两种解压结果必须逐字节一致；压缩副本与原文件保持相同修改时间。Candy 的图片、脚本和样式均生成内容哈希名称；文本资源使用固定的 `br-` 发布前缀，以绕开 CDN 已缓存的旧 gzip-only 版本，此前缀不随每次发布变化。实验页和开发工具不进入发布目录。

主页背景保留 4093×1842 原尺寸，增加 AVIF（质量 90、4:4:4）版本，从 1,313,302 字节降至 929,533 字节。相对原 JPEG 解码像素，RGB PSNR 48.12 dB、平均绝对通道误差 0.518/255；这属于近无损转换，并非逐像素无损。头像增加 192/384 像素无损 WebP（51,082 / 173,006 字节），浏览器按显示密度选择；原始 1024 像素 JPEG 保留。`picture` 选择的背景图同时供 CSS 降级展示和 WebGL 纹理使用，避免两种格式重复下载；不支持 AVIF 或 AVIF 加载失败时回退到原 JPEG。玻璃参数、渲染分辨率和场景采样不变。

Nginx 配置模板位于 `deploy/nginx/`：cache map 放在 `http` 上下文，static snippet 仅由 Candy / YARD 的 HTTPS server 引入。服务器先安装 Ubuntu 官方仓库的 `libnginx-mod-http-brotli-static`，再启用 HTTP/2、brotli_static、gzip_static 和文本类型动态 gzip；高压缩工作在构建时完成。带内容哈希的资源缓存一年并标记 immutable，HTML 必须重新验证，未带哈希的图片缓存一小时。仅成功响应附加缓存头，避免把不存在的哈希资源 404 缓存一年。Cloudflare 的现有 HTTP/3 配置保留；源站压缩的节省不等于浏览器侧同等比例的收益。修改后必须先 `nginx -t` 再平滑 reload，并验证源站 / CDN、两种解码一致性、不接受压缩的客户端、ETag 304、404 和所有章节入口。

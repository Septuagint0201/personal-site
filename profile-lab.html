关于形体、光学和参数统一 ＋

曲线决定从外缘到内部的厚度，而非只改变高光。截面和立体预览读取同一个归一化轮廓；宽度不足的小控件会缩短肩部过渡，厚度保持设定值。Bézier 拖点限制为单调曲线，避免表面翻折。

光学预览基于闭合玻璃体的界面求交、Snell 折射和 Fresnel 反射，包含有限次数的全内反射处理；并非完整多反弹路径追踪。极窄肩部和高折射率下可切换实体形体检查边界。导出的 v1 JSON 包含尺寸、轮廓、光学参数及采样表，可作为其他 UI 渲染器接入统一材质的依据。
